- [ ] **同幀識別延伸到 RTMP 與丟棄原因**：目前 VT 同幀觀測與 RTMP 入列嘗試序號尚未串成同一識別。補齊跨階段關聯及受限容量的丟棄摘要，涵蓋佇列滿、節流、等待 keyframe、舊世代及停止；成功入列不當作遠端收到或解碼成功。
- [ ] **音訊重採樣前後逐批關聯**：已有 AudioTimelineAudit 累計時長、世代、補零與丟棄計數；尚無逐批來源到輸出對照。設計能表達一批拆多批／多批合一批的有界關聯，並補 AAC AudioCodec 轉換器摘要；不能假設每個 buffer 都是單一 1024-sample packet。
